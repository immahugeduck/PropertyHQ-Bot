## Examples checked between upgrades

| Checkpoint | Example | Observed result |
| --- | --- | --- |
| 1 | `Yes permission granted.` plus punctuation/case variants | Permission saved on the original repair; no repeated question. |
| 1 | Passive refusal, conditional answers and a different kind of question | No unrestricted entry inferred; refusal saved when explicit. |
| 2 | New report and permission update | Maintenance receives one work order; manager receives tenant context and saved facts. |
| 2 | `Maybe, I need to check.` | Manager gets the context; no duplicate maintenance scheduling alert. |
| 2 | Repeated unchanged permission | Existing staff suggestion and proposal version retained; no duplicate maintenance alert. |
| 2 | Form-created screen repair | Same work-order format, tenant acknowledgement, and manager context. |
| 2 | Permission revoked after booking | Scheduled time retained; maintenance gets the current access restriction. |
| 2 | Another account or public client role requests a work order | No cross-account result; public client calls denied. |
| 3 | Washer report → permission → maintenance approval | Permission alone leaves the visit unbooked; approval books the displayed slot and informs the tenant. |
| 3 | Sink/disposal report → no unattended entry → approved choices | Three staff-approved options; tenant agrees to the exact selected visit. |
| 3 | `Those times don't work. Weekdays after 4 PM instead.` | Availability saved, old selection cleared, old database proposal rejected. |
| 3 | Distinct bedroom window-screen report after washer intake | Separate repair; permission stays with the question's job. |
| 3 | Existing appointment/status/completion and a repeated delivery SID | Saved state recalled and updated; duplicate delivery creates no ticket or alerts. |
| 3 | Suggested slot becomes occupied before staff approval | Booking rejected; no false confirmation to the tenant. |
| 3 | `I smell gas in the kitchen.` | Safety response and emergency manager alert; no normal booking prompt. |

The rescheduling example has maintenance supply revised exact times. Free-text availability is saved and shown to maintenance; these tests do not claim that arbitrary natural-language availability is automatically converted into calendar constraints.
